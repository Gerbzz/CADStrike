# CADCraft foundation candidate

This branch retains the original CADStrike part editor at the repository root and adds a separate Rust workspace at `foundation/`. The candidate is based on CADCraft commit `c57879a5c8f5e3a6be574a820add5e28eb25e9b1` from `storytold/cadcraft`. Its `craft-ui` dependency is pinned to `storytold/craft-libs` commit `5c874d51eeb3de70e735c8ce87a59a7dedd47675`. The full source diff in the original isolated candidate is preserved here, including the strict legacy project reader, donor command and selected-file sketch import. The copied workspace uses its own `Cargo.lock` and has no dependency on the older CADStrike crate at the root.

## Available workflow

From `foundation/`, run `cargo run --locked -p cadstrike`. The desktop uses CADCraft's drawing tools, dimensions, constraints, selection, undo and native DXF file workflow. In the File menu, **Import CADStrike sketch** asks the user to choose an existing `.cadstrike` bracket or disk project. It validates the source, creates a separate metric 2D drawing with stable source-ID to CADCraft-handle mapping, and leaves the source file and previously open drawing intact. Save the resulting drawing as DXF to continue editing in this candidate. Invalid or oversized legacy files report an error without replacing the active drawing. The imported sketch geometry is 2D; it does not carry the old part's extrusion as an editable solid.

The import uses a dedicated legacy-sketch picker with a `.cadstrike` filter, separate from the ordinary DXF/DWG/SVG drawing picker. Newly imported geometry is marked unsaved so interactive Close and Quit ask before discarding it. Cancelling selection preserves the active drawing. Programmatic imports continue to accept validated source bytes without opening a file picker. See the [source/build audit](SOURCE_BUILD_PROVENANCE.md) for the regression tests, completed native build and bounded runtime checks.

From the repository root on Windows, the primary launcher is `./scripts/Start-CADStrike.ps1`. Use `-PlanOnly` to inspect its manifest, target directory, donor pin and build identity without building or launching. Use `-BuildOnly` to compile without opening the desktop. The launcher always uses this foundation workspace, locked dependencies and a separate `foundation/target` directory, and passes the Git revision to the existing `CADCRAFT_BUILD_SHA` hook. A changed checkout is marked `-dirty`; an archive without Git identity is marked `unversioned`.

For the original part workflow, run `cargo run --locked --features native-ui --bin cadstrike-ui` from the repository root. Its `.cadstrike` v1 file remains the editable bracket/disk source, with STL export through the existing CLI. The foundation does not replace that executable or silently convert its files.

Both workspaces have a package named `cadstrike`. The root package's `cadstrike` binary is the legacy CLI. The foundation package's `cadstrike` binary is the CADCraft desktop. Always identify the manifest and target path; the filename alone is insufficient. The retained screenshot in the root README is explicitly a legacy-editor capture. The [source/build audit](SOURCE_BUILD_PROVENANCE.md) records a separate source-matched native foundation capture and its limits.

## Review evidence and remaining work

The October 21 continuation completed 58 focused Rust tests across the converter, engine, import UI, donor dialog dispatch, desktop and original root workflow, plus the native Windows check/build and launcher contract tests. The native executable from clean `6a104ff` reported that source identity, displayed the full donor editor, produced a genuine native capture and passed a source-preserving import/unsaved-close smoke test. Exact commands and evidence are recorded in the source/build audit. This branch's Windows CI runs the focused gates and builds the foundation desktop with required Windows identity resources.

The OS file picker and broader pointer, keyboard, scaling and accessibility workflows still need manual acceptance. The legacy `.cadstrike` format and CADCraft DXF are distinct; a unified editable Strike container, 3D feature history, solid viewport, old-file precision repair, assembly workflow and cross-platform testing are not finished.

`foundation/LICENSE-MIT`, `foundation/LICENSE-APACHE`, `foundation/NOTICE`, `foundation/ATTRIBUTION.md` and `foundation/STRIKE-REDISTRIBUTION-NOTES.md` remain with the donor code. The excluded ArtCraft brand artwork and CADCraft app icons were not copied. The desktop Windows icon is generated from original Strike source; About uses the approved transparent CADStrike logo already in the parent repository, with its original provenance. `acadrust` 0.6.3 is an unconditional native dependency under MPL-2.0; `colored` 2.2.0 is also MPL-2.0 in the lockfile. Dependency notice/source closure, exact release graph, and binary packaging need review before distribution. The working names are not trademark-cleared.

The upstream sparse checkout omitted packaging assets and documentation screenshots. The two public contributor metadata files were restored byte-for-byte from the pinned donor commit so the About panel can credit upstream contributors. No release package or external example-drawing collection is claimed from this source copy. The workspace app code, built-in sample and focused tests are present; the audit records the local Windows verification and CI provides repeatable review gates.
